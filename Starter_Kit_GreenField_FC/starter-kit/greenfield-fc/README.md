Danh sách

1. Chuẩn bị môi trường và cấu trúc thư mục dự án
2. Khởi tạo kho lưu trữ Git và thiết lập tệp `README.md`

   * Viết tiêu đề và đoạn mô tả tổng quan dự án
   * Thêm bảng quản lý thư mục và các khối mã lệnh cần thiết
3. Kiểm tra tính bảo mật và đẩy mã nguồn lên [GitHub](https://github.com)



* Cài đặt phần mềm Visual Studio Code và các tiện ích hỗ trợ Markdown
* Cấu hình terminal PowerShell với các quyền thực thi cần thiết
* Tạo các tệp tin cấu hình bảo mật dự án (như tệp `.gitignore`)
